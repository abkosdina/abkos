# Authentication Module Status

این سند وضعیت فعلی ماژول Authentication در این مخزن را منعکس می‌کند. در نسخه‌ی فعلی، تمرکز اصلی روی API و منطق بک‌اند است و هیچ بخش فرانت‌اند جداگانه‌ای در این پروژه نگهداری نمی‌شود.

## وضعیت فعلی

- احراز هویت از طریق لایه‌ی بک‌اند و سرویس‌های Laravel انجام می‌شود.
- ورود با OTP و مکانیسم‌های مرتبط در سطح سرویس و کنترلر پیاده‌سازی می‌شوند.
- دسترسی‌ها و محدودیت‌ها از طریق middleware و policies کنترل می‌شوند.

## حوزه‌های مهم

- AuthenticationServiceProvider
- کنترلرهای احراز هویت
- Middleware و policyهای دسترسی
- تعامل با UserManagement و KYC

## نکته مهم

- مستندات قدیمی مرتبط با UI یا componentها در این نسخه به‌عنوان روایت تاریخی نگهداری شده‌اند و برای توسعه‌ی جاری معیار نیستند.
