# Documentation Hub

This folder now contains the project documentation in a structured layout.

## Structure

- overview/: general project and onboarding documents
- workflow/: workflow and approval engine documents
- database/: schema, migration, and database audit documents
- implementation/: implementation plans, summaries, and guides
- maintenance/: audits, cleanup, and legacy notes
- modules/: module-specific documentation
- architecture/: architecture references and module maps
